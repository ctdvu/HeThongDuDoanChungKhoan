Biểu Diễn Toán Học: HỢP CÁC HÀM (Function Composition)

ŷ = (f₇ ∘ f₆ ∘ f₅ ∘ f₄ ∘ f₃ ∘ f₂ ∘ f₁)(X₃₀ₓ₄₀)

Dữ liệu đầu vào chuỗi thời gian X qua mỗi tầng biến đổi sẽ được nén và trừu tượng hóa dần, tạo ra xác suất phân loại nhị phân ŷ ∈ (0, 1) đại diện cho khả năng giá tăng vào phiên kế tiếp.
f₁
LSTM Layer 1
256 units
return_sequences=True, L2=1e-4. Trích xuất đặc trưng ngắn hạn.
f₂
LSTM Layer 2
128 units
BatchNorm + Dropout 0.3. Nhận diện chu kỳ trung hạn.
f₃
LSTM Layer 3
64 units
return_sequences=True. Tổng hợp pattern đa chiều.
f₄
LSTM Layer 4
32 units
return_sequences=False. Nén toàn bộ chuỗi về 1 vector đặc trưng.
f₅
Dense Layer 1
64 units
ReLU activation + BatchNorm + Dropout 0.20. Học phi tuyến.
f₆
Dense Layer 2
32 units
ReLU activation. Tinh chỉnh không gian phân lớp.
f₇
Output Layer
1 unit (Sigmoid)
σ(z) = 1/(1+e⁻ᶻ) → Xác suất tăng P(Up ∈ [0, 1]).

1. Các hàm cổng của Cell LSTM:
  • Forget Gate: fₜ = σ(W_f · [hₜ₋₁, xₜ] + b_f)
  • Input Gate: iₜ = σ(W_i · [hₜ₋₁, xₜ] + b_i)
  • Candidate: C̃ₜ = tanh(W_c · [hₜ₋₁, xₜ] + b_c)
  • Cell State Update: Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ
  • Output Gate: oₜ = σ(W_o · [hₜ₋₁, xₜ] + b_o)
  • Hidden State: hₜ = oₜ ⊙ tanh(Cₜ)
2. Hợp hàm xử lý Feature Pipeline:

D_feat = (g_label ∘ g_macd ∘ g_vol ∘ g_vola ∘ g_mom ∘ g_ma ∘ g_ret)(D_raw)

Mỗi hàm phụ trách trích xuất một khía cạnh riêng biệt của thị trường: Đà tăng trưởng, Biến động, Khối lượng và Xu hướng.
